# 判定方法、指标与限制

## 两套判定

| 头 | 依据 | 用途 |
|---|---|---|
| **戾气分**（规则） | 手写信号：指向人、脏话/威胁、阴阳套话、反问、居高临下、标点/emoji | 论坛日常语气，覆盖“不明骂但阴阳” |
| **强攻击**（模型） | COLD 上训练的字符 2/3-gram + 可解释特征逻辑回归，p≥0.85 才亮 | 只在明确脏话/侮辱时标红，避免误伤 |

## 规则头权重

| 信号 | 权重 | 例子 |
|---|---|---|
| 指向人的攻击 | 40 | 「你这人」「你也配」；14 字内有 你/您/他/楼主 才满权重，否则 ×0.45 |
| 贬义称谓 | 16 | 垃圾、小丑、水军、孝子；指向人 ×1.6 |
| 脏话 | 26 | 他妈的、傻逼；`啥逼样` 这类变体走正则 |
| 暴力威胁 | 30 | 邦邦两拳、揍你、弄死 |
| 阴阳套话 | 11 | 典、赢麻了、您可真、已严肃学习、说得对 |
| 立场贬损 | 9 | 智商税、洗地、晦气 |
| 居高临下 | 7 | 水硕、水中水、就这、自欺欺人、低能 |
| 反问 | 7 | 凭什么、哪来的、这也叫 |
| 问号密度 | 4 | 一句 ≥2 个问号，最多叠两档 |
| 绝对化 / emoji / 标点轰炸 | 4 / 8 / 4 | 一点都…、🙃😅🤡、？？？ |

`raw` 累加后 `100·(1-e^(-raw/60))` 映射到 0–100，分档：`<12 平和 / <30 有火药味 / <55 阴阳/对立 / ≥55 攻击性`。

防误伤：`垃圾佬` 先屏蔽（社区褒义）；`典`、`菜`、`绷` 走带边界正则；单字词不做裸子串。

## 模型头

- 特征：21 个可解释量（各词表命中数、长度、人称、@、数字、latin 比例、重复字符、密度…）+ 字符 2/3-gram 哈希 16384 桶
- 训练：COLD train（25,726 条），SGD 12–30 epoch，L2；dev 选阈值，test 报数
- 产物：`src/model.js`（约 200KB，纯数组）

## 指标（COLD test，5323 条，攻击性占比 39.6%）

| 方法 | acc | prec | recall | F1 |
|---|---|---|---|---|
| 纯规则（阈值 10） | 0.672 | 0.709 | 0.290 | 0.412 |
| 逻辑回归 p≥0.5 | 0.703 | 0.596 | 0.776 | **0.674** |
| 逻辑回归 p≥0.85（扩展实际用的档） | — | **0.889** | 0.228 | — |

## 数据源

- **COLD**（thu-coai/COLDataset，EMNLP 2022）：中文攻击性语言基准，Weibo 语料，`label 1=offensive`
- **ToxiCN**（DUT-lujunyu/ToxiCN，ACL 2023）：分级有毒语言标注 + `lexicon/{general,sexism,racism,region,LGBT}.json`，只取无歧义条目
- 反讽：**NTU-Irony-Corpus**、**Dataset_Chinese_Ciron**（尚未接入）

## 限制

1. **域偏移**：模型学的是微博骂战。本机 156 条真实论坛回复上 p 中位 0.25、最高 0.61——正常帖不会亮“强攻击”，但论坛式冷嘲它抓不到，仍靠规则。
2. **反讽靠套路词**：没有套路词的陈述式冷嘲会漏；「说得对」这类真心话会轻微误伤。
3. **看不到的内容算不出**：被删的楼、TL2/TL3 可见的帖、待审核的帖。
4. **列表页只有标题**，分数按 0.6 折算，只作导航。

## 重训

```bash
mkdir -p /tmp/cold && cd /tmp/cold
curl -LO https://raw.githubusercontent.com/thu-coai/COLDataset/main/COLDataset/{train,dev,test}.csv
cd - && node test/train.js /tmp/cold
```

要用论坛自己的语料，准备 `label,text` 两列的 CSV，替换 `test/train.js` 里的 load 路径即可（特征、训练、导出都不变）。
